# 🛍️ Fake Store - Frontend

**Fake Store** é um e-commerce criativo e completo, com produtos fictícios pensados exclusivamente para o universo dos programadores. Este repositório representa o **frontend** da aplicação, desenvolvido com foco em experiência de usuário, desempenho e integração total com a API.

---

## ✨ Tecnologias Principais

- **ReactJS** (via Vite)
- **Styled-components**
- **Axios** (consumo de API)
- **React Router DOM**
- **React Context + Hooks**
- **Stripe Checkout (simulado)**
- **CI/CD via Vercel**

---

## 📋 Funcionalidades

- Página inicial com carrossel de categorias
- Catálogo de produtos únicos (com imagens geradas por IA)
- Carrinho de compras persistente
- Histórico de compras por usuário
- Login, registro e recuperação de senha
- Integração com pagamento via Stripe
- Sistema completo de autenticação com tokens JWT

---

## 🎨 UI/UX

- Design responsivo e 100% funcional
- Componentes reutilizáveis com Styled-components
- Carrossel animado de categorias
- Layout pensado para fluidez e clareza da navegação
